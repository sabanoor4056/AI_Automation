# 🤖 AI Automation

A modern **AI Automation web application** built with **Django** to demonstrate practical automation, lead management, dashboard functionality, and AI-focused web development.

The project is designed as a portfolio application to showcase how web technologies and automation can be combined to build useful business-oriented solutions.

## 🚀 Project Overview

**AI Automation** is a Django-based web application that provides a structured platform for managing automation-related workflows and business data.

The project focuses on building a clean, scalable, and user-friendly system with features such as dashboard management, lead management, and an organized interface for future AI automation modules.

It is developed with a focus on **practical automation, backend development, database management, and professional web application design**.

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/AI_Automation.git
```

### 2. Open the Project

```bash
cd AI_Automation
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

**Mac/Linux:**

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Apply Database Migrations

```bash
python manage.py migrate
```

### 7. Start the Development Server

```bash
python manage.py runserver
```

Open the application in your browser:

```text
http://127.0.0.1:8000/
```
